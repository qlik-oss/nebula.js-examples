# Advanced Chart Template

This folder contains a multi-file nebula chart template intended for skill-driven scaffolding.

## Files

- src/index.js
- src/data.js
- src/object-properties.js
- src/ext.js
- src/components/root.jsx
- src/components/AdvancedChart.jsx
- src/components/chart.css

## Usage

1. Copy these files into a chart project created with @nebula.js/cli.
2. Fill in TODO sections for your chart-specific data transformation and rendering logic.
3. Keep the lifecycle and cleanup patterns intact to avoid memory leaks and print/snapshot issues.
